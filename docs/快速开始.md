# 快速开始（Quick Start）

> 从零开始：启动环境 → 放置数据 → 训练 → 查看结果 → 使用结果。
> 完整图文详解见 [YOLO分割训练与预测操作指南.md](YOLO分割训练与预测操作指南.md)。

---

## 1. 启动项目环境（Docker）

### 1.1 前置条件

- Docker Desktop（WSL2 后端）+ NVIDIA Container Toolkit
- 宿主机 GPU（本项目实测 RTX 5060 Ti，16G 显存）

### 1.2 确认镜像存在

```bash
docker images | grep yolo
```

不存在则构建：

```bash
cd /mnt/c/path/to/YOLOWorkbench
docker build -t yoloworkbench:cuda12.8 -f docker/Dockerfile .
```

### 1.3 启动容器并进入

```bash
cd /mnt/c/path/to/YOLOWorkbench
./docker/run_wsl.sh        # WSL/Linux；Windows PowerShell 用 ./docker/run.ps1
```

**成功标志**：提示符变为 `root@<容器ID>:/workspace#`。
**验证环境**：

```bash
python3 -c "import ultralytics, torch; print(ultralytics.__version__, torch.cuda.is_available())"
# 预期：8.4.x True（True = GPU 可用）
```

> 容器内 `/workspace` = 宿主机 `/mnt/c/path/to/YOLOWorkbench`（同一目录，双向同步）。

## 2. 准备数据集

### 2.1 数据集放置位置

把数据集文件夹放入 `datasets/`，标准 YOLO 分割格式：

```
datasets/<数据集名>/
├── data.yaml            # 数据集配置（必须）
├── images/Train/        # 训练图片
└── labels/Train/        # 对应标注（同名 .txt）
```

### 2.2 修正 data.yaml

```yaml
path: datasets/<数据集名>     # 相对项目根目录
train: images/Train
val: images/Train             # 无独立验证集时先这样占位
names:
  0: crack
```

> 注意：不要用导出工具生成的 `.txt` 清单（路径常带多余前缀），直接写目录最可靠。

### 2.3 无标签图片的验证集（可选）

只有图片、没有标注的文件夹（如 `datasets/your-inference-images/`）**只能做推理测试**，不能作为 val。

---

## 3. 启动训练

### 3.1 分割训练（裂缝检测，推荐）

```bash
cd /workspace
python python/train_seg.py
```

或命令行方式：

```bash
yolo segment train \
    data="datasets/your-segmentation-dataset/data.yaml" \
    model=yolo11n-seg.pt \
    epochs=200 imgsz=640 batch=16 patience=50 device=0 name=segmentation
```

### 3.2 检测训练（COCO 示例）

```bash
python python/train_detect.py
```

### 3.3 关键参数

| 参数 | 建议 | 说明 |
|------|------|------|
| `model` | `yolo11n-seg.pt` | 分割预训练权重，首次自动下载 |
| `epochs` | 200 | 配合 `patience` 早停 |
| `batch` | 16 | 按显存调整，OOM 减半 |
| `device` | 0 | GPU；无 GPU 改 `cpu` |
| `name` | 自定义 | 输出目录名 |

---

## 4. 查看训练结果

训练输出在 `runs/segment/<name>/`（宿主机直接可看）：

| 文件 | 用途 |
|------|------|
| `results.png` | **曲线总图**（loss 下降、mAP 上升 = 正常） |
| `results.csv` | 每轮精确指标（实时查看：`tail -f runs/segment/<name>/results.csv`） |
| `weights/best.pt` | **最优权重（部署用它）** |
| `weights/last.pt` | 最后一轮权重 |
| `val_batch*_pred.jpg` | 验证集预测效果图 |

> 重要提醒：若 val 与 train 同源，mAP 数字偏乐观，真实效果以新图推理为准。

## 5. 使用训练结果（推理）

### 5.1 对单张图/整个文件夹推理

```bash
yolo segment predict \
    model=runs/segment/segmentation/weights/best.pt \
    source="datasets/your-inference-images" \        # 图片、文件夹、视频均可
    conf=0.25 save=True \
    project=runs/predict name=test
```

结果（带分割掩码的图）输出到 `runs/predict/test/`。

### 5.2 转 ONNX 部署（可选）

```bash
yolo export model=runs/segment/segmentation/weights/best.pt format=onnx
```

> C++ 部署（ONNX Runtime）见 README「编译并运行 C++ 推理」。

## 6. 常见问题速查

| 问题 | 解决 |
|------|------|
| `yolo` 命令找不到 | 还没进容器，先 `./docker/run_wsl.sh` |
| `docker run -it` 卡住没反应 | 用脚本（`-d` 后台 + `docker exec` 进入） |
| `unable to allocate shared memory` | 容器需 `--shm-size=8g`（脚本已内置） |
| 图片找不到 | 检查 `data.yaml` 的 `path`/`train` 路径 |
| GPU 不可用 | 宿主机装 NVIDIA Container Toolkit，容器加 `--gpus all` |
